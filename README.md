# Luke Morris — Cybersecurity Portfolio

A complete static GitHub Pages portfolio with a professional homepage, eight capability pages, role-aligned navigation, synthetic dashboard previews, project index, and reusable report templates.

## Publish
Upload the **contents** of this directory to the root of the public repository `lukedm0164-git.github.io`. GitHub Pages → Deploy from a branch → main → / (root).

## Editing later
- `assets/site-data.js`: site identity, GitHub link, and capability descriptions.
- `index.html`: homepage content.
- `pages/*.html`: each technical page.
- `assets/style.css`: shared design system.
- `docs/`: reusable report and project templates.

## Truthful portfolio convention
All dashboards are marked **Synthetic preview**; project cards are **Planned**. Replace them only with genuine work. Never publish real sensitive data, secrets, or unauthorized network logs.

## No subscription required
All site features run as static HTML/CSS/JS on GitHub Pages. Google Fonts is optional and the design falls back to system fonts. No paid hosting, build tool, or database required.
