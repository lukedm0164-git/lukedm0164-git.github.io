# Luke Morris Cybersecurity Portfolio

Static GitHub Pages starter site.

## Publishing
Create a public GitHub repository named `YOURUSERNAME.github.io`. Upload the **contents** of this folder to the repository root. Under Settings → Pages, select Deploy from branch, main, /(root).

## Updating
Edit `index.html` for homepage content, `pages/*.html` for each skill page, and `assets/style.css` for appearance. Replace placeholders only with completed work. Never publish real credentials, sensitive IP addresses, private data, or unauthorized security logs.
