# SOC Portfolio Visual Design System (v1.0)

The original dark theme, aqua highlights, terminal design, and existing logos are retained. The architecture diagram uses a light background for readability. New pages should use these shared CSS variables.

| Token | Color | Usage |
|---|---|---|
| Background | `#070D17` | Main site background |
| Panel | `#101C2D` | Cards and content panels |
| Aqua | `#63E7D0` | Links, buttons, active UI |
| Blue | `#76AAFF` | SIEM, monitoring, analytics |
| Green | `#268766` | Endpoints and validated status |
| Purple | `#7360A8` | Cases and reports |
| Amber | `#F7C56C` | Work in progress |
| Red | `#B4454A` | Attack simulation / warnings |

Keep vendor logos in their original colors. Do not present planned lab features as complete.
