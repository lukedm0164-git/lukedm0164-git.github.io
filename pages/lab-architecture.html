01 · Attack simulation

Kali Linux generates controlled activity within the isolated lab. Test events provide material for security monitoring and investigation.

02 · Target endpoints

CentOS, Windows 11, and Ubuntu Desktop produce operating-system logs and observable network traffic.

03 · Detection and analysis

Wazuh collects endpoint telemetry; Splunk supports log analysis. Wireshark captures traffic. Suricata network IDS placement and integration remain under configuration.

04 · Incident response

DFIR-IRIS runs via Docker Desktop on the Windows host, not on a seventh VM. The planned workflow tracks evidence, investigation findings, and case notes.

05 · Reporting

SOC Report Studio is a separate reporting application under development. Reviewed, sanitized project reports and documentation can be published to GitHub.

06 · Validation status

VM host-only IPs are established and VM traffic has been observed in Wireshark. End-to-end integration and detection tests are ongoing; the architecture describes the intended complete workflow.

Investigation workflow

Simulate → Collect → Detect → Investigate → Document → Publish. Generate authorized test events, inspect packet traffic, collect endpoint logs, investigate alerts, preserve evidence, and create technical reports. Separate confirmed capabilities from planned integrations.
